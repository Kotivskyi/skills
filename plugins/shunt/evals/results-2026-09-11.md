# Shunt evaluation record: 2026-09-11

We tested Shunt on copies of Pastorix's PostgreSQL error helper and four caller or test files.
Source copies, generated files, and traces stayed outside this repository. The five backend inputs stayed unchanged.

## Method

In the first loop, we ran a baseline, two improvement rounds, and two repeat checks.
We reserved the follow-up and missing-context cases until we finished the second candidate.
All 12 runs used the same source hashes, Pi settings, worker overrides, and parent model.

The parent used Claude Code 2.1.268 with `claude-opus-5[1m]`.
Pi 0.84.2 used `openai-codex`, `gpt-5.6-terra`, and high thinking.
Independent reviewers checked source, saved outputs, tool events, and Jest results. They excluded model thinking text.
The runner's `review_required` status does not mean that a case passed.

## Selected changes

- Load [code-writer](../skills/code-writer/SKILL.md) before drafting a complete file from references.
- Use [bulk-reader](../skills/bulk-reader/SKILL.md) before broad source reads. Do not reconstruct a blocked full read with chunks.
- Include each exported function's contract in test specifications and parent review, as required by code-writer.
- Preserve comparison rules. Separate visible behavior from comments and missing implementation evidence, as required by bulk-reader.

In the first loop, the worker scripts, their options, and Pi settings stayed unchanged.
The 58 offline checks and plugin validation passed. Both edited skills passed skill-creator validation.
A path-alias defect in the transport checks was also fixed and checked through macOS `/tmp`.

## Gaps after the first loop

- Both round 2 bulk reports wrote `code === code` instead of comparing the error property with the supplied code.
  Pi supplied the correct expression. The parent introduced the error in the saved report.
- The missing-context case skipped Pi in both versions. Its answer identified missing production evidence but included unsupported general claims.
- Some report runs invoked Jest on Markdown. This unnecessary check did not satisfy any rubric expectation.

We kept the measured improvements and stopped after the two planned rounds. We did not repair outputs to raise scores.
This small evaluation does not establish general reliability or cost savings.
The 12 parent calls reported USD 4.4908935. That amount excludes Pi calls and setup probes.
The focused Jest checks do not replace the backend's full repository checks.
